反面的根因是只用前三个顶点计算凹多边形法向。修复后按完整边界计算法向，在构件的面全部生成后校正；原生检查同时验证边方向和带符号体积，避免把“闭合”误判为“面朝向正确”。

Windows 原生测试使用 File.identical? 检查测试文件身份，避免正反斜杠造成误报；斜扶手圆截面的竖向投影不等于完整半径，最高点检查使用中心线与半径给出的区间。

所有原生修改只在独立进程和明确命名的空白测试模型中执行。SketchUp 保存时出现“清除未使用项”提示则选择“否”继续，未更改全局偏好。用户已有的未保存 SketchUp 会话保持不动，也未写入用户 Plugins 目录。原始报告、修复前对照和合成模型位于被 gitignore 排除的 `test-results/windows-beta2-20261101/`，不作为公开发布资产。
