# 功能路线

## 0.1 测试版已实现

- 独立插件入口与命名空间，可与原空间推敲台同时安装。
- 按层高生成、点选两端位置；直跑、双跑直梯、L、U 型。
- 平台、左右转、梯井、踏步板厚、单／双侧圆管扶手与立柱。
- 苹果桌面面板风格；参数即时预览、轴测旋转、平面和侧面查看。
- 读取组件参数并原位更新、复制件隔离、单次事务与失败回滚。
- MIT、来源说明、贡献说明、可复现打包和跨平台 CI 配置。

## 0.1 稳定版前

- 在空闲的 SU 2026 专用会话完成实体、放置、选点、撤销、复制更新、关闭重开与保存重开验收。
- Windows 实机检查中文路径、窗口尺寸、工具捕捉与扩展加载。
- 检查各梯型的扶手转角连续性与开放踏步表现。
- 增加合成 SKP 样例和基于最终原生结果的截图。

## 后续迭代

- 斜板、锯齿、开放踏步的结构表现切换。
- 独立控制各平台和每一侧护栏，扶手端部延伸、转角连接及栏杆填充。
- 多跑与多层楼梯、扇形踏步和螺旋梯。
- 楼板开洞边界提示、净空与碰撞可视化。
- 参数预设、英文界面、旧工作台楼梯的显式导入。

后续条目是规划；不会在当前测试版中显示为已支持。
